# Party Night

모바일 가로 브라우저에서 플레이하는 4인 파티 기반 다이스 던전 게임입니다. v0.1.0 플레이 루프를 유지하면서 v0.2.0의 7개 퀘스트·Lv10 성장 구조와 단계 10 회귀 검증까지 구현했습니다.

## 실행

```bash
npm install
npm run dev
```

검증 명령:

```bash
npm run typecheck
npm run test
npm run build
```

## 조작과 흐름

1. 메인 캐릭터의 이름, 종족, 직업, 성별을 선택해 profile v2를 생성합니다.
2. 거점의 퀘스트 탭에서 순차 퀘스트 5개와 해금 후 반복 퀘스트 2개에 입장합니다. 창고 빈칸이 2칸 이하이면 계속 진입하거나 창고로 돌아갈 수 있습니다.
3. 탐사 화면 Canvas의 `FWD`, `BACK`, 좌우 회전 버튼으로 이동하고 HUD의 탐사 아이템을 사용할 수 있습니다.
4. `(3,1)`, `(5,3)`, `(3,5)`에서 세 고블린 파티와 순서대로 조우합니다.
5. 로웬의 `조준 사격`은 굴림 직후 다이스 하나를 리롤하거나 원래 결과를 확정할 수 있습니다.
6. 세 번째 조우에 승리하면 즉시 퀘스트가 완료되어 골드 1,100과 캐릭터당 EXP 100을 얻고 전원이 Lv2가 됩니다.
7. 결과 화면에서 성장·고블린 소굴·고급 장비 해금과 커스텀 스킬 보상 3개를 확인합니다. 창고가 부족하면 보관할 보상을 선택한 뒤 거점으로 돌아갑니다.

화면은 `640 × 360` 논리 해상도와 모바일 가로 방향을 기준으로 합니다. 세로 방향에서는 입력을 가리는 회전 안내가 표시됩니다.

## v0.2.0 단계별 구현 상태

- 최신 전투·경제·후반 보스 밸런스를 `raw_data_table.md`와 `implements.md` 26절 기준으로 반영했습니다. 고정 동료는 신규 profile부터 브람(드워프)·세라(인간)·로웬(엘프)을 사용하며 기존 profile의 저장 종족은 보존합니다.
- 종족·직업·시작 무기는 기본 능력치와 파생 전투 수치에 반영됩니다. 성별과 전열·후열은 수치에 영향을 주지 않습니다.
- Phaser는 v0.2.0의 map별 terrain 7종, 일반/보스 조우 마커와 적 16종 registry를 사용하며 7개 퀘스트 전체에 연결됩니다. 누락·로딩 실패 시 기존 도형으로 개별 fallback합니다.
- 아이템·장비·스킬은 포션, 장비 family 8종, 액티브/패시브의 11개 대표 아이콘을 사용합니다. 장비는 일반/고급/희귀/영웅/전설을 흰/녹/파랑/보라/노랑색과 한글 배지로 함께 표시합니다. 다이스는 아직 도형으로 표시합니다.
- profile v2, 순수 `gameEngine`, 저장 adapter와 거점 UI를 구현했습니다. 100칸 통합 창고, 일반 장비·초기 소비 아이템 상점, 장비 교체·판매, STR 기반 개인 인벤토리 배분·회수를 사용할 수 있습니다.
- 승인된 소비 아이템 9종을 정의했고 진행도에 따라 상점에서 해금됩니다. 개인 인벤토리에 배분한 회복약·화염병·탐색용 분필·정화약·강장제는 허용된 전투·탐사 상황에서 사용할 수 있으며 붕대는 `응급 치료` 비용으로 사용합니다.
- 훈련 폐허 3조우, Lv2 직업별 성장, Lv2 직업 스킬 해금, 고급 장비 상점과 창고 초과 스킬 보상 선택이 구현되었습니다.
- 고블린 소굴 3조우와 홉고블린 보스, Lv3 성장·첫 커스텀 슬롯, 함정·비밀문·비밀방 보상, 커스텀 스킬 장착·상점이 구현되었습니다.
- 유적지 4조우와 오크·오우거 보스, Lv4 성장, 희귀 장비 9종, 오우거 강타 기절, 단계 5 소비 아이템 사용을 구현했습니다. 오크·오우거·유적지는 가져온 전용 draft 에셋을 사용하며 로딩 실패 시에만 도형 fallback을 사용합니다.
- 지하 던전 5조우와 놀 중간보스·미노타우르스 보스, Lv5 직업 스킬, 출혈·기절·마비·수면·약점 노출·신경독·능력 변화와 CD5, 영웅 장비 해금을 구현했습니다.
- 옛 고성 5조우와 구울 중간보스·리치 보스, Lv6 성장, 전설 장비와 반복 퀘스트 2개 해금을 구현했습니다.
- 화산 동굴·깊은 숲 폐허의 반복 플레이, 사이클롭스·스켈레톤 킹 보스, 반복 횟수, Lv7~10 성장과 두 번째·세 번째 커스텀 슬롯을 구현했습니다.
- 단계 10에서 전체 122개 자동 테스트, production build, 100회 혼합 반복·저장 reload·overflow, 844×390 Chromium 가로 실행과 390×844 세로 차단을 검증했습니다. Android Chrome·iOS Safari 실기 검증은 별도 기기가 필요합니다.
- 저장 키는 `party_night_profile_v2`입니다. version 1 저장은 읽거나 변환·삭제하지 않으며 진행 중 원정·HP·위치·전투 상태는 저장하지 않습니다.

게임 판정은 React와 Phaser에 의존하지 않는 `src/game` 순수 TypeScript 엔진에서 처리하며, 세션 이후 모든 난수는 시드 PRNG를 사용합니다.
