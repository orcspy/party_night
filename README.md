# Party Night

모바일 가로 브라우저에서 플레이하는 4인 파티 기반 다이스 던전 MVP입니다. 캐릭터 준비, 1인칭 격자 탐사, 고정 조우, AGI 기반 턴제 전투, 선택 리롤, 보상과 프로필 저장까지 한 사이클을 제공합니다.

## 실행

```bash
npm install
npm run dev
```

검증 명령:

```bash
npm run typecheck
npm run test
npm run build
```

## 조작과 흐름

1. 메인 캐릭터의 이름, 종족, 직업, 성별을 선택합니다.
2. 탐사 화면 Canvas의 `FWD`, `BACK`, 좌우 회전 버튼으로 훈련 폐허를 이동합니다.
3. `(3, 5)`의 고정 조우에서 React 명령 패널로 스킬과 적을 선택합니다.
4. 로웬의 `조준 사격`은 굴림 직후 다이스 하나를 리롤하거나 원래 결과를 확정할 수 있습니다.
5. 승리 후 `(5, 5)` 출구로 이동하면 골드 100과 경험치 50을 얻습니다.
6. 결과 화면에서 준비 화면으로 돌아갑니다. 프로필과 누적 보상만 브라우저에 저장됩니다.

화면은 `640 × 360` 논리 해상도와 모바일 가로 방향을 기준으로 합니다. 세로 방향에서는 입력을 가리는 회전 안내가 표시됩니다.

## MVP 임시 사항

- 직업 수치, 스킬 수치, 고정 동료, 고블린 2종, 훈련 폐허 맵과 보상은 `src/game/content.ts` 및 구현 사양의 임시 데이터입니다.
- 종족, 성별, 전열과 후열은 표시 정보이며 전투 수치에 영향을 주지 않습니다.
- Phaser 캐릭터와 탐사 벽은 최종 에셋 대신 도형으로 표시합니다.
- 계정, 서버 저장, 장비와 상점, 성장, 회복, 상태 효과, 사운드, 다중 퀘스트는 MVP 범위에 포함하지 않습니다.
- 저장 키는 `party_night_mvp_save_v1`이며 진행 중 세션, HP, 위치, 전투 상태는 저장하지 않습니다.

게임 판정은 React와 Phaser에 의존하지 않는 `src/game` 순수 TypeScript 엔진에서 처리하며, 세션 이후 모든 난수는 시드 PRNG를 사용합니다.
